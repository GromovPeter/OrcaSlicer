# Interlayer adhesion and temperature calibration

The Calibration menu creates a normal Orca project containing a native cylinder mesh, spiral-process settings and native custom G-code events by height. Current printer, filament and plate provide context without duplicating their selectors in the form. The operator supplies wall width, layer height, test flow and descending temperatures. Width and speed are applied to unsaved process edits, temperatures and disabled adaptation to unsaved filament edits. Printing uses the ordinary Slice plate and Print plate controls. No external postprocessor, printer-side macro installation or separate script is involved.

## Geometry and conditions

The core planner uses Orca's rounded-rectangle extrusion section and the filament flow ratio to convert requested deposited volume per second into path speed. It sizes the cylinder to satisfy the filament's minimum layer time with a margin, a minimum useful diameter and a conservative curvature/acceleration allowance. Bed-edge and exclusion clearance, maximum axis speed, filament flow ceiling and printable height constrain the result. An infeasible plan is rejected instead of silently changing its flow or dwell. The hollow print has no solid bottom, a brim and warmup turns outside the measurement, avoiding the material and time cost of a wide solid floor.

Fan settings are inherited unchanged from the filament. Layer-time slowdown is inherited by default. The explicit "Disable layer-time slowdown for this calibration" checkbox instead disables only `slow_down_for_layer_cooling` in the unsaved calibration filament edit. Sizing then uses a two-second minimum turn and the same curvature/machine limits, while thermal transitions and stable dwell are still rounded up to complete turns. This permits high flow without a bed-sized circumference, but changes cooling between layers. The original saved preset is untouched. Warmup extends beyond its first-layer fan ramp. The process disables support, raft, fuzzy skin and ironing, and uses one wall with a fixed layer height and width; ordinary temperature adaptation, coordinated flow and adaptive volumetric speed are disabled for this experiment. Initial and ordinary nozzle targets both use the requested starting temperature. Layer-change G-code is restricted to comments, extrusion-coordinate resets and print statistics; start/end printer G-code remains normal. Current support is one material slot, one Klipper hotend and a horizontal bed, without external postprocessing.

## Temperature-to-height map

Each descending step emits nonblocking M104 at the start of a full spiral revolution. Native custom-by-height insertion occurs before a layer rises from its preceding Z, so the event's matching layer Z is one layer height above the physical start height stored in the map. Cooling height is the ceiling of (1.25 times fall-reference times temperature step plus additional lead reference) divided by revolution time, expressed as whole revolutions. This is a provisional scheduling reference, not sensor feedback or a proven thermal ramp model.

Stable height is at least three complete revolutions and five seconds, rounded upwards. An advanced override can increase this height, but cannot reduce the automatic minimum. Minimum diameter is also an advanced lower bound. The final temperature retains its complete stable section; the model ends naturally and normal printer end G-code runs. Preflight reports diameter, height, section heights, wall volume and wall-time estimate. Native preview remains authoritative for complete timing, including brim, initial-speed differences and machine startup.

A versioned JSON height map is stored in the first custom M104 event's comments. It persists with native custom commands in 3MF and exported G-code without new configuration keys. Export reconstructs the required settings and verifies geometry, the full temperature schedule and recorded fan/load conditions. Stale geometry, settings or custom events are rejected. The acceleration-aware flow timeline is collected only for calibration/adaptive projects. Measurement-wall flow is checked after native cooling and motion planning: its aggregate mean must be within three percent of requested flow and at least 95 percent of deposited volume must occur on commands within five percent. A failed check rejects calibration export; it does not relax machine limits. This validates commanded extrusion planning, not actual melt flow or missed steps.

## Reading a result

The height entry refers to the remaining cylinder measured from the build plate. The stored map distinguishes warmup, cooling transition and stable-section target; a transition yields a temperature interval rather than a fabricated exact sensor temperature. Copying a stable result gives a flow/temperature pair. Explicit application inserts or replaces only that flow in the edited filament table, requires a strictly increasing table, and leaves adaptation disabled. Conflicting existing guesses require review in normal filament settings; the result remains copyable. Normal preset saving remains an explicit action.

Peeling is a practical threshold test whose result depends on material, cooling, layer geometry and force application. Stable-section target is not measured melt temperature or an automatic working-temperature recommendation. Repetition and a suitable working margin remain part of interpreting a physical test.

The normal vase taper-out duplicates the final revolution with decreasing extrusion. Calibration export suppresses that extra revolution so the top remains at the measured flow; ordinary vase projects retain the existing finish.

The optional `disable_layer_time_slowdown` height-map field records this policy when true. Absence means false, and false is omitted on serialization to retain exact schedules for existing B6 projects. Stored conditions reflect the effective slowdown setting, so export succeeds after applying the intentional override and rejects re-enabling slowdown without recreating the calibration. Fan thresholds and fan-speed settings remain unchanged.

## Preview and creation lifecycle

Calibration creation suppresses background-update scheduling while it applies process/filament edits, imports the cylinder and assigns its complete height schedule, then schedules one update. The preview slider preserves marked calibration schedules when switching into spiral mode or displaying sequential printing; its normal removal of unsupported color/tool ticks remains unchanged for ordinary projects. Preview round trips may leave the display mode undefined and round layer Z through float. Export accepts these representation-only changes (height tolerance 0.0001 mm), while still checking every command, metadata comment, type, extruder, ordering, count and meaningful height change. The presence check used by preview does not parse or trust the JSON: malformed maps still reach normal export validation instead of being silently removed.
